# H5 界面

从 [主入口](../SKILL.md) 进入面向手机浏览器的 H5 页面设计时读取；桌面后台和原生 App 仍走各自平台路径。

H5 页面默认使用 [daisyUI](https://daisyui.com/docs/install/) 作为组件样式基础。沿用项目现有 React、Vue 或原生 HTML 结构，以项目语义 tokens 定义主题；daisyUI 5 按官方要求经 Tailwind CSS 4 构建。存量项目先盘点已有组件和样式入口，再在获准范围内迁移，保留表单值、事件与导航行为。用户明确指定其他组件体系或项目约束不允许接入时，记录原因与本次替代方案。

daisyUI 提供组件样式，不替复杂交互处理焦点、键盘、弹层定位和状态恢复。按页面实际需要沿用或补充与项目框架相容的行为组件，并在手机视口与触控设备上验收。
