# 太空视觉主题

太空主题从轨道曲线、行星地平线、稀疏星点和观测界面的清晰刻度中提炼空间关系。它适合探索、科研、航天、数据叙事和需要表达广阔尺度的展示场景；使用前仍以产品任务、品牌与受众为准。本站的三张画面是原创概念图，用于解释构图，不是天文观测照片或科学数据。

## 视觉规则

| 层 | 做法 | 边界 |
| --- | --- | --- |
| 构图 | 大块安静留白承载标题和任务；一条轨道弧线或地平线连接当前状态与下一步 | 弧线只用于展示区、分区外缘或进度路径；表单和数据仍沿稳定网格对齐 |
| 色彩 | 浅色以冷雾白和深海军蓝保证阅读；深色以夜空蓝和雾白建立远近，电光青只强调操作和焦点 | 主操作与成功、警告、错误分别取值；避免整页霓虹蓝紫渐变 |
| 材质 | 远景可用低对比星点与柔和光晕；中景用细边框分组；前景用不透明实色表面 | 正文、表格、代码、图表数据、弹窗和证据背后不铺星点或透明玻璃 |
| 字体 | 中文正文使用平台可读无衬线；数字和坐标可局部使用等宽字体 | 长文和按钮不使用极细字重、全大写或过宽字距 |
| 动效 | 短暂地显示轨道推进或状态切换，静止帧保留当前状态 | `reduced motion` 直接显示终态；不持续闪烁、漂浮或模拟穿梭 |

## 语义与组件

浅色和深色的具体角色见 [太空 token 样本](../assets/space-theme.tokens.json)。组件消费 `background`、`surface`、`text`、`primaryAction`、`onPrimaryAction`、`primaryContainer`、`onPrimaryContainer`、`focus` 和独立状态色；不要直接把“星光色”写进业务组件。浅色主题的主按钮为深蓝底白字，深色主题为亮青底深字。选中项在两种模式下都用填充或边框加文字标识；焦点另有清楚的 2px 轮廓。加载、空、错误与成功状态保留文字说明和可继续的动作。

## 接入与验收

先读[统一 token 契约](token-contract.md)，将两种明暗模式映射到目标产品已有组件和平台交互。核对桌面、窄屏、200% 放大、键盘、触控、打印与减少动态效果；检查正文、次级文字、主按钮、选中项、焦点和状态在实际背景上的对比度。当前随包报告和原生预设仍以青山湖为准；此文件与 token 样本提供太空主题的设计方向，不能替代产品内的组件验收。
