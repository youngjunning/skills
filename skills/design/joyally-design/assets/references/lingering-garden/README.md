# 留园视觉参考

四张苏州留园照片来自同一园林，分别记录入口、水边亭台、小蓬莱与曲廊水院。成组观察曲廊的转折、山石的引导和建筑与水面的连续视线，再提炼温暖石色、木棕和浅砂表面的主题表达。照片是设计依据；组件仍需独立完成语义 token、状态和对比度映射。
