# 蒸馏行为回归

以下为合成材料，不是用户事实，不写入真实目标。维护时对每个案例实际给出候选、目标去重动作、最终状态与报告，再与预期比较。脚本单测只验证可确定的结构约束，不能替代这些语义检查或证明未来召回率。

| 案例 | 输入及目标条件 | 预期行为 |
| --- | --- | --- |
| R1 明确判断 | “我认为有了内置脚本，就不需要独立命令工具了。”目标可写且无同记录 | 新增判断，保留“我认为”；缺少量化理由不阻断 |
| R2 项目选择 | 上句后补“这个项目也没必要做独立命令工具”；工程 README 已如此，记录库未收录 | 还原项目指代，合并为同事件判断；工程文档不作为去重命中 |
| R3 未成熟想法 | “我还没想清楚，也许检索可以先不用数据库。” | 作为想法保存，保留不确定语气；不写成已决定或已验证 |
| R4 命令中有选择 | “不要新增服务，继续用当前脚本。” | 提取技术选择；不因句式为命令而全排除 |
| R5 普通操作 | “把这次修改提交一下。”无其他内容 | 可排除；完成五类审阅后无新增，不制造经历 |
| R6 只有 Agent 建议 | Agent 提议引入队列，用户只问价格 | 不把建议归为用户决策；资料分支独立判断 |
| R7 未说理由 | “我选 B。”相邻消息明确 B 是方案，不含选择原因 | 保存选择，理由未知；不复制 Agent 推荐理由 |
| R8 真正重复 | 目标同事件、对象、立场已保存，并已读取稳定 ID | duplicate，引用现有身份和等价依据 |
| R9 真实改变 | 目标旧记录选 A，用户现在明确改选 B | 新建关联变化；不覆盖旧立场，不视为同主题重复 |
| R10 跨目标 | 内部判断可分享，公开只允许通用摘要 | 各目标独立审查；保留同身份，公开不含精确出处与内部名称 |
| R11 部分失败 | 内部校验回读成功，公开写入后校验失败 | 内部新增，公开 failed；不整体报成功或无新增 |
| R12 待接入 | 用户说“有设备后再验证”；目标无待办映射 | research candidate，说明缺映射，不塞入经历 |
| R13 用户收藏 | 用户要求收藏已核验公共资料，未采用 | reference，主动收藏；采用状态未知 |
| R14 概念解释 | 有完整 AI 辅助解释、依据、假设例子和适用边界，目标授权 | concept；不声称用户掌握，不因无个人事实而跳过 |
| R15 截断 | 较早有用户判断，尾部全是 Agent 进度 | 摘录披露遗漏，按原话恢复；不能仅看尾部报无新增 |
| R16 元数据混排 | 环境上下文块后同消息包含“我改选 B” | 忽略环境块，保留真正用户请求 |
| R17 只输出 | 用户要求只输出，默认目标已配置 | 不读写默认目标；列候选，不能称已入库 |
| R18 受众拒收 | 有意义但私密，配置仅允许公司或公开目标 | 不写源文件、Git 或公开回执；以适当粒度报告未保存 |
| R19 恢复重试 | 上次已写入，校验中断；目标现在有同身份 | 回读并继续校验，按实际变更统计，不重复插入 |
| R20 一句多项 | “选 B，另外保留文档链接，设备到了再验证。” | 分别提取判断、资料、待办，所有来源互相对应；不能保存一项就结束 |
| R21 未决设计问题 | 用户要求产品支持某种新环境；本轮只确认大方向，关键运行形态仍待选择，目标支持研究清单 | 保存有具体下一步的研究项，AI 提议的下一步标记为建议；不因未说“以后研究”漏掉 |
| R22 授权的会话发现 | 目标明确允许自动发现，用户观点与 AI 补充条件形成有价值的转折，尚无同片段 | 以 discovered 保存短片段，区分原话与摘要、说话者与来源；不冒称用户逐条精选 |
| R23 同轮解决或撤回 | 用户先说“回头看看方案”，随后本轮完成验证或明确取消 | 不留下开放研究项；如有独立价值，按其他适用类型判断 |
| R24 未授权的公开会话 | 内部目标允许会话发现，公开目标仅接受本人挑选且有公共来源 | 内部可保存合格发现；公开只列候选，不传播内部会话 ID 或原话 |

若无法进行独立 Agent 行为验证，明确报告为规则走查；不把表格存在、关键词命中或审计单测通过称为端到端语义评测通过。
