# 阿尔卑斯雪山视觉参考

主题取景范围为瑞士伯尔尼阿尔卑斯山的少女峰地区，包含少女峰、翁根、少女峰山口和阿莱奇冰川。20 张照片从远眺、近观、山谷和冰川视角呈现同一区域；共同线索是清晰的山脊、雪与岩的明暗面、谷地引导线和大面积天空或雪原。画面用于研究构图与种子色，不直接充当产品背景或组件素材。
