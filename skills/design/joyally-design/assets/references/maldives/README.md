# 马尔代夫视觉参考

四张马尔代夫实景照片从空中岛屿、礁盘、海面色带和岸上椰林观察同一群岛目的地。马尔代夫是群岛而非单一景点；画面只支持提炼浅海、白沙、深海与岛屿边缘的共同特征，不宣称拍摄于同一座岛。界面主题用弧形分界、开阔海面和高明度留白组织信息；正文和操作始终使用有足够对比度的实色表面。
