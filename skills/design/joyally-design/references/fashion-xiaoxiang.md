# 小香风视觉主题

小香风指香奈儿风格，是与青山湖、西湖、苏州园林、马尔代夫和阿尔卑斯雪山并列的视觉主题。它从[20 张服装与织物参考照片](../assets/references/xiaoxiang/README.md)中观察经典套装的短外套与裙装比例、黑白对比、米色面料、滚边、金色纽扣和编辑式呈现，再转译为界面语言。粗花呢属于局部材质线索，不能代替主题身份。主题表达风格借鉴，不使用香奈儿商标或暗示品牌授权。

## 何时选用

适合个人主页、作品集、编辑式内容站和重视审美表达的展示页。高频工作台也可以使用此配色，但应保持原有的信息密度与组件行为。先确认产品品牌、内容、主要动作与受众，再决定使用多少织纹和装饰；明确已有品牌规范时以该规范为准。

## 视觉规则

| 层 | 做法 | 边界 |
| --- | --- | --- |
| 构图 | 大块浅色留白、细分隔线、规整的横向编排；展示区用编辑式标题关系 | 阅读和操作顺序先于装饰，移动端保持清楚的单列次序 |
| 色彩 | 象牙白画布、暖白阅读表面、黑色文字与主操作、米色层次；暖金只用于细节和焦点 | 暖金不兼任成功、警告或错误；小字用深墨或足够深的次级色 |
| 材质 | 米色面料与黑色细滚边表达主要轮廓；粗花呢低对比纹理只放在展示区或卡片外缘 | 正文、表格、表单、代码和证据使用不透明纯色表面，不在文字后铺密集织纹 |
| 字体 | 中文正文使用平台可读无衬线；大标题可用适合中文的宋体或品牌字体，字重 600–700 | 不用极细字重、稀疏点阵或低对比度来制造精致感；长标题在实际窄屏核对断行 |
| 几何 | 外层可用 1px 深色滚边与小圆角，卡片轻微错层；控件形状保持一致 | 焦点、选中和 hover 不改变尺寸；避免层层套框和过多阴影 |

先翻看[20 张参考图及逐张来源](../assets/references/xiaoxiang/README.md)，从造型、面料细节和画面编排提炼主题，再按任务选择展示强度。色值和语义映射见 [小香风 token 样本](../assets/xiaoxiang-theme.tokens.json)。样本同时给出浅色和深色的 `background`、`surface`、`text`、`primaryAction`、`onPrimaryAction`、`primaryContainer`、`focus`、`success`、`warning`、`error` 等角色。组件只消费语义角色；织纹、滚边和字重属于主题视觉层，不能替换状态语义。产品有自己的 token 命名时将这些角色映射到现有系统。

## 组件与状态

- 导航当前项用深墨底或清楚的描边，并保留文字标识；键盘焦点另用可读的暖金焦点环。
- 主按钮用深墨底与浅色文字，次按钮用暖白表面与深墨描边；disabled 同时降低强调并保留标签可读。
- 卡片可用一条深色上边或轻微错层建立节奏；空、加载、错误与成功状态分别提供文字和可继续的动作。
- 输入、筛选、图表和长文维持实色背景。图表类别沿用产品的语义色，不把所有数据系列改成粉色。
- 动效只用于切换与反馈；减少动态效果时直接显示最终状态。点阵或粒子标题若承载文字，静止帧必须能直接读出字形。

## 落地核对

在代表页检查桌面、窄屏和 200% 放大：首屏主要内容与下一步能否一眼读出；正文、按钮和焦点是否有足够对比；织纹是否离开阅读区；深色模式与打印是否保留层级；键盘、触控和减少动态效果下状态是否完整。此样本不自动替换 Joyally Design 现有青山湖预设，也不宣称其他平台已经完成组件实现。
