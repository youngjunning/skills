# H5 界面

从 [主入口](../SKILL.md) 进入面向手机浏览器的 H5 页面设计时读取；桌面后台和原生 App 仍走各自平台路径。

Joyally 自有 H5 新界面使用 [daisyUI](https://daisyui.com/docs/intro/) 作为组件样式基础，通过 Tailwind CSS 4 插件或官方独立 CSS 用法接入。服务其他产品或改造存量页面时，先沿用项目现有组件、React、Vue 或原生 HTML 结构，以项目语义 tokens 定义主题；只有现有基础无法满足本次需求且已确认迁移范围时才换组件。选择组件时保留表单值、事件与导航行为。

daisyUI 提供组件样式，不替复杂交互处理焦点、键盘、弹层定位和状态恢复。按页面实际需要沿用或补充与项目框架相容的行为组件，并在手机视口与触控设备上验收。
