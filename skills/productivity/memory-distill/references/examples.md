# 证据与表达示例

以下均为虚构示例，不对应真实会话、个人或项目。

## 短回复要还原对象

Agent 提出记录、对外交流、执行代办三个方向，用户说“三个都做，先建记录”。可记录明确的范围和先后顺序；不能补写降低成本、提高效率等用户未表达的理由。正文需要独立说明对象，不能只保存“三个都做”。

## 建议与本人选择分开

Agent 建议新增服务，用户只要求继续修复问题，不能记为用户采纳新增服务。资料中的第一人称也不能成为当前用户的经历。

## 补全与变化分开

旧记录缺少场景时补全并保留 ID；只有真实立场变化才新增关联变化记录。一次工作区修改不等于提交、发布或使用者验收。

## 公开与内部来源分开

获准公司共享的内部资料可在内部保存必要短摘录和精确证据位置；含个人私密信息的原文与出处留在个人私有位置。公开版本只保留可公开的本人陈述摘要或正式公共来源。不把内部链接替换成虚构公共地址，也不复制原始会话和安装配置。

## 各分支的判断案例

下表用于检查判断是否混用；它不授权写入示例数据，也不证明未来会话一定会按规则执行。

| 输入与现有条件 | 应执行的结果 | 错误结论 |
| --- | --- | --- |
| 用户只问某项技术是什么；查到有具体复用用途的官方文档，目标已授权自动收藏 | 个人记忆无候选；文档按 discovered 收藏，注明用途、来源和未知项 | 没有个人事实，所以没有可收藏内容 |
| 调研中列出一个尚未采用的工具，来源与用途已核验 | 可以按 discovered 收藏；没有采用证据时 adoption 为 unknown，不填写使用记录 | 没试用或没选用，所以不能收藏 |
| 用户未说“收藏”，但会话已有自动收藏授权，目标支持该类型 | 合格资料直接写入；不是仅列候选等待确认 | 用户本轮没点名收藏，所以没有授权 |
| 用户问一个概念，形成有来源的完整解释、假设示例与适用边界，目标支持 card | 按 discovered 保存概念笔记，context 标明资料整理或 AI 辅助解释；不新增个人理解记录 | 不能证明本人已掌握，所以连概念笔记也不保存 |
| 只提到一个术语，或已收藏文档摘要没有增加解释与使用场景 | 不制造概念笔记；仍独立检查参考资料是否合格 | 为保证自动收录，每个术语都生成笔记 |
| 已有同概念笔记，但本轮发现旧解释有误 | 修订原笔记并保留 ID，核对来源和公开版本 | 发现重复概念，所以任何修正都跳过 |
| 同 URL 已收藏，本轮补充了可靠出处或更正未披露边界 | 更新既有条目，保留 ID；原 selection 为 explicit 时不降级 | URL 重复，所以全部跳过或再新增一条 |
| 本轮无个人记忆、参考资料或概念笔记候选，Skills 用途摘要有变化 | 三类内容可无新增；独立同步 Skills，并执行已授权的触发统计 | 没有收藏，所有收尾流程都跳过 |
| 内部无新条目，但有上轮失败的公开同步项 | 按已知待处理 ID 核对公开内容并补齐；不扩成全库扫描 | 内部无变化，所以公开一定已同步 |
| 公开端已有同 ID，但摘要或来源仍是旧版本 | 比较本轮应公开字段并更新，验证后才标已同步 | 同 ID 已存在，所以同步完成 |
| 内部写入并回读成功，公开目标校验失败 | 内部报告已写入；公开报告未完成及失败原因，继续其他不依赖它的已授权分支 | 一个目标成功就称两端完成，或全部称已跳过 |
| 触发统计正在等待另一会话；本轮取消了自己的等待 | 说明本轮统计未完成及主动取消等待；保留原统计，不终止另一会话，不把 summary 当本轮扫描结果 | 未扫描等于新增零次，或取消也只归因于被占用 |
| 目标仅支持参考资料，不支持概念笔记 | 资料正常处理；笔记只列候选并注明目标能力缺失 | 一种类型不支持，全部收藏都不处理 |
| 工作仓库的会话里讨论个人求职计划，未授权公司读者接收 | 不写公司目标、附件或来源；无个人私有目标时只输出候选 | remote 为 internal，所以把原话先放公司仓库 |
| 个人公开站有面试或求职文章，本轮核对反向同步 | 先判断针对公司读者的授权；没有授权则跳过该方向 | 已公开，所以公司站也能自动收录 |
| 新写公司技术文章，公开端尚无同 ID，记录与收藏没有增量 | 独立审查文章和全部资源，合格版本按同 ID 同步并校验 | 个人记忆无新增，文章也不用核对 |
| 已脱敏公开文章引用了内部截图或附件 | 先审查资源内容与可访问性，通过后才写目标；否则跳过或修订 | 正文已删公司名，就能直接提交 |
| 两站同 ID 文章有不同正文，公开端有独立修订 | 比较本轮事实、目标修订与受众差异，保留有效修订 | 文件指纹不同就直接覆盖，或同 ID 就认为已同步 |
| 内站已有 Wiki，公开站只新增空数据文件 | 公开 Wiki 仍待实现，受众限制只影响数据 | 模块有同名文件，所以能力已经一致 |

这些案例覆盖候选类型、授权、去重、同步与执行状态。校验时应检查实际决定及输出内容，不能只搜索文档是否出现某句规则。
