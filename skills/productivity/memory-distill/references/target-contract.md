# 目标接入约定

接入文件是供 Agent 阅读的 Markdown，不需要新增服务或配置解析器。按需调用选择指定目标；自动模式可按本机配置依次选择多个目标，每个目标独立审查授权与验收。

处理流程与结果状态统一使用 [处理协议](pipeline.md)。接入文件只定义下述目标差异，不另设候选筛选门槛或隐式启用文章、清单与统计任务。接入产生的保存、去重和失败证据返回候选的该目标结果，不能覆盖其他目标状态。

配置可以直接包含接入说明，也可引用目标根目录和接入文件。相对路径以声明文件所在目录为基准，数据路径以声明的目标根目录为基准。目标不存在或映射不足时，只输出候选及缺项。

接入需明确：

1. 根目录、数据文件、schema 和约定入口，必要时明确记录主体。
2. 支持个人记录、参考资料、概念笔记、研究待办、精选会话中的哪些类型，以及正文、时间精度、未知值、出处、类型、身份、关系和去重的字段映射。待办需映射问题、下一步和状态；片段需映射角色、正文、来源和选择方式。
3. 谁能读取源文件、Git、展示页、附件、索引、API 与模型上下文；哪些内容已获保存授权，原话和精确出处存在哪里。
4. 写入后的校验、回读要求及已有 Git 操作权限；有页面需求时声明验收方式。

保留目标原有格式，不要求 JSON、固定字段或特定网站。某类型不支持时只限制该类型，不自动创建数据文件。安装技能和提供配置不等于授权发布、历史扫描或保存敏感信息。

参考资料按 URL 或资源身份去重，分别映射主动收藏与会话发现、用途、来源、核验和实际使用关系。概念笔记注明解释归属、示例是否假设与适用边界。目标可以采用自己的优先级、状态和关联字段。

未配置目标时只输出候选；用户指定目标时不再读取默认目标。自动蒸馏与多目标规则见 [automatic-distillation.md](automatic-distillation.md)，研究待办及精选会话见 [research-and-excerpts.md](research-and-excerpts.md)。每轮统计遵循实际内容变更；文章发布、清单与 Skills 使用统计不由目标接入隐式启用。
