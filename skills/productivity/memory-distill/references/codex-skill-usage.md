# Codex 技能触发统计

仅在所选本机目标配置包含 `skill_usage`、明确授权历史范围和私有状态位置时执行。首次扫描完成回填，以后每轮收尾运行同一 `scan` 命令；`summary` 只查询已有结果。统计脚本只读日志，不执行日志中的命令、不保存正文、不扫描 Claude 历史。

```bash
python3 <本Skill目录>/scripts/codex_skill_usage.py scan --state <私有本机目录>/codex-skill-usage.sqlite3 --progress
python3 <本Skill目录>/scripts/codex_skill_usage.py summary --state <私有本机目录>/codex-skill-usage.sqlite3
```

`--codex-home` 默认取 `CODEX_HOME` 或 `~/.codex`。扫描其 `sessions/` 与 `archived_sessions/` 中的 JSONL，以及通过本机 `zstd` 解压读取的 `.jsonl.zst`；不使用只有用户输入的 `history.jsonl`。缺少解压工具、文件不可读或待解析的完整 JSON 行损坏时保留该文件的旧统计，返回非零和错误列表；不得将部分成功汇报为全量完成。无关记录按类型跳过，不作日志完整性审计；末尾尚未写完的一行留待下轮读取。

## 计数口径

计数指标是 `verified_skill_read_turns`：同一原始轮次、同一技能名称最多一次。它是可核验的加载次数下界，不能证明流程执行成功、使用熟练度或收益，也不能保证涵盖已删除、未落盘或其他设备的历史。

接受直接 shell 工具或 `functions.exec` 中字面量 `exec_command` 的 `cat`、`head`、`sed` 读取，且关联工具结果必须含该技能的完整 frontmatter（名称、描述及两侧分隔符）。不执行 shell 或 JavaScript 来推导动态路径。结果截断、路径别名与 frontmatter 不匹配、异步结果无法关联、动态脚本读取和仅注入上下文等情况不计，作为当前检测能力的遗漏边界。

清单注入、搜索命中、路径提及、助手声称使用、读引用文件、失败读取，以及工具输出中引用其他技能均不构成触发。用户当轮明确涉及技能维护、安装、清单、审查、读取或统计时，整轮读取排除；这一保守规则也可能排除当轮真正使用的辅助技能，不能把剩余次数称为精确总量。

轮次优先使用日志原始 `turn_id`；旧日志回退到真实用户消息的时间与内容摘要。fork 或会话复制保留原轮次标识，重复读取、复制日志、归档副本和重复执行扫描均不增加同一轮次计数。旧记录缺少可用轮次则排除。同名技能合并计数；历史改名前后的不同名称分别保留，不猜测身份映射。

## 增量、隐私与验收

SQLite 保存逐文件偏移、解析上下文、调用标识、技能名称、时间和行号，不保存用户消息或工具正文。未变化的文件不读；追加文件从上次完整行继续；截断、边界变化或压缩文件变化时重读对应文件并替换其观察结果。解析口径变化时维护者递增 `PARSER_REVISION`，下次扫描自动重建检查点，逐文件成功后替换观察结果。文件锁串行化并发会话，单文件事务失败保留旧值。已成功统计后被移除的日志仍保留历史证据，不将文件清理视作负触发次数。

状态库、锁文件和输出均只保存在配置指定的私有本机目录，不加入技能仓库、个人记录、收藏夹或公开站点；公开同步只更新技能用途摘要，不携带本机统计和证据。用户另行要求展示统计时再约定脱敏字段。

变更脚本后运行 `python3 -m unittest discover -s <本Skill目录>/scripts -p 'test_*.py'`。回填后核对 `scan.errors`、文件数和排除项，再执行一次扫描，确认无新日志时触发数不变、文件标为 unchanged；追加、复制/fork、维护与读取失败由合成日志测试验证。每轮最后一次更新可能看不到尚未落盘的当前调用，由下一轮补齐；不宣称已验证未来会话自动执行。
