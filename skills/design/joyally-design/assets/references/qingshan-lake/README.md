# 临安青山湖视觉参考

青山湖主题同时吸收春、夏、秋、冬的树列、湖面、光线与雾色，形成一套固定的语义色和界面结构，不按季节切换皮肤。目标是每季 5 张经核实拍摄地点、时间与许可的实拍照片。当前春 2 张、夏 0 张、秋 0 张、冬 1 张；另有 3 张已记录来源但拍摄季节未核实的照片。空缺保留，不用旧视频截帧充数。

| 季节 | 已核实 | 目标 | 观察线索 |
| --- | ---: | ---: | --- |
| 春 | 2 | 5 | 新绿、柔光、树列与开阔湖面 |
| 夏 | 0 | 5 | 浓绿树冠、水面浮萍与阴影 |
| 秋 | 0 | 5 | 渐变杉叶与暖色倒影 |
| 冬 | 1 | 5 | 清冷晨光、疏朗树列与雾 |
