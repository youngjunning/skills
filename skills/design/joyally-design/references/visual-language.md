# Joyally Design 视觉体系：中国风审美

Joyally Design 以中国风审美组织界面。这里的“中国风”是留白、远近、框景、路径和材料的设计方法，不等于固定朝代符号、装饰纹样或风景照片。近处清楚可操作，远处安静而有层次；用户先看见任务、内容和下一步，再感到场景的气息。辨识度来自语义色、距离、材质和节制的共同作用。

## 共同规则

留白为内容和操作留出呼吸空间；远近让前景承载行动、中景组织导航、远景提供氛围；框景与路径帮助聚焦并引导阅读；语义 token 保持状态、对比度和交互含义一致。这些规则从现有主题的共性中提炼，进入设计语言后约束后续实现；新增主题也可以反过来校准和丰富共同规则。

## 三种平等的视觉主题

主题是一套可复用的界面表达，定义构图、色彩、材质、节奏及其到语义角色与组件状态的映射。取景地是主题的来源属性，提供景观线索和参考画面，不等于主题本身；换一处取景地也不必重新定义整套主题。三种主题在体系中地位平等；实现进度不同不改变层级。

| 主题 | 当前取景地 | 空间组织 | 色彩与材料 | 当前实现 |
| --- | --- | --- | --- | --- |
| 疏林静水 | 青山湖水上森林：湖面、水杉、远山与季节光影 | 疏林形成纵向节奏，水面和雾白留出阅读空间 | 湖色操作、水杉绿反馈、青瓷釉表面 | 已有页面展示；现有四季、报告和平台 token 以此实现 |
| 长桥远望 | 西湖：开阔水面、桥的动线、远塔与岸线 | 桥引导视线，远塔作为安静的定位点，页面保留大块明净空间 | 深湖青操作、暖纸白阅读表面、少量石桥暖灰 | 已有页面展示；产品 token 尚需逐项映射和校验 |
| 游廊框景 | 苏州园林：白墙、曲线屋檐、框景、游廊与植被 | 以框景组织模块，路径有收有放，内容层级清楚 | 黛青操作、粉墙纸白表面、少量瓦灰与竹绿 | 已有页面展示；产品 token 尚需逐项映射和校验 |

三处取景地的画面分别保存在[青山湖参考目录](../assets/references/qingshan-lake/README.md)、[西湖参考目录](../assets/references/west-lake/README.md)和[苏州园林参考目录](../assets/references/suzhou-gardens/README.md)。青山湖的 14 张视频截图用于观察水杉、湖面和季节光影；原视频作者与授权未随截图提供，内站画册只将其作为设计研究资料展示，不作为可复用产品背景。西湖和苏州园林各有两张本地高清照片，作者、来源与许可见目录说明；内站另外保留各一张封面照片。画面用于取色和空间观察，不替代组件、token 或布局规则。

三种主题共用 `Seed → Map → Alias → Component`、操作与状态的语义、可读性和组件状态。选主题先看产品任务与品牌，再借当前取景地的景观线索校准种子色和版式；明暗、四季与材质在主题内继续变化。不能把取景地照片的颜色直接写进业务组件，也不能声称尚未映射的主题已覆盖所有平台。

## 「疏林静水」现有预设的色彩映射

| 视觉线索 | 界面职责 | 使用边界 |
| --- | --- | --- |
| 雾白 | 画布、留白和低噪声底色 | 大面积保持温和，正文与数据放在清晰表面 |
| 湖色 | 主操作、当前位置、焦点和进度 | 使用可读的深色变体，状态同时有文字或形状 |
| 水杉绿 | 该预设的成功、在线、生长与完成 | 与主操作区分；其他方向可换种子色，不改变语义 |
| 远山灰蓝 | 次级文字、结构、边界与退后的信息 | 保留可读对比度，不用低对比度制造“朦胧” |
| 晨光暖色 | 少量高光、提醒和季节线索 | 不铺满画布；警告、错误使用各自的语义 token |

上表是「疏林静水」当前取景于青山湖水上森林的具体映射，不代表体系的唯一配色。颜色从 `Seed → Map → Alias → Component` 派生。组件消费语义角色，不直接消费风景色名；主题、浅色、深色与四季可以变换色值，操作、状态和层级的意义保持稳定。已实现的具体值与对比度以 [统一 token 契约](token-contract.md) 和随包 token 文件为准。

标题与正文使用满足对比度的中性文字色，不把文字色列为品牌强调色，也不用它铺大面积表面。

## 空间与材质

- 远近由信息层级表达：前景是主要内容和动作，中景是导航与工具，背景承接氛围。对齐、字号、间距和表面先建立顺序，再加入雾、光或景观图形。
- 以 8px 节奏组织内容，4px 处理局部关系；桌面工作台保持紧凑，阅读页面给段落留足宽度和呼吸，移动端服从触控热区与系统字体缩放。西湖可用长动线连接章节，园林可用框景划分章节，但都不应牺牲导航和扫读。
- 青瓷釉是现有青山湖预设中温润、偏实的表面；玻璃用于外缘、导航或定位上下文。表格、表单、代码、日志、证据和长文保持不透明。每层只保留一个清楚的材质边界。
- 雾气、水纹、叶影与光斑只在外缘、空态或展示区点到为止。画面可以借景，不把真实风景照、密集插画或连续装饰放在任务前面。

## 字体、图像与动效

优先使用平台可读字体或产品已有品牌字体。标题、正文、标签和数字按阅读顺序区分；中文长标题、窄屏断行与字体放大必须在实际尺寸检查。图像承担内容或情绪时先确定它与文字和操作的关系，避免把图当作填空装饰。

交互动效解释状态变化和空间连续性，通常短而明确；雾与光若缓慢移动，应停在阅读区外，并在页面隐藏或减少动态效果时停止。静态画面仍须能表达当前状态和下一步动作。

## 验收辨识度

在真实页面上检查：主操作与阅读锚点是否一眼可见；远近层次是否帮助扫读；每个主题的颜色是否映射到明确的语义职责；材质是否保住正文与证据的对比度；去掉装饰后任务是否仍走得通。报告、工作台与原生界面可以有不同密度和组件形态，但共享这套语义关系。服务其他品牌时复用方法与状态契约，视觉身份由该品牌决定。
