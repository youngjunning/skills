# Chrome 扩展图标

扩展图标的验收画面是浏览器工具栏中的小图，不是单独打开的高清源图。先确认扩展做什么、已有品牌与图标、工具栏背景和项目 Manifest；与既有 UI 保持同一视觉身份。

1. 选一个在小尺寸仍能认出的主体轮廓。控制形状和颜色数量，避免靠细线、微小文字、柔光或复杂渐变传达含义。需要新源图时调用 `joyally-image` 的图标流程；已有源图只需调整裁切、透明度或尺寸时，直接处理源图，不重复生图。
2. 先在最终显示尺寸检查，再决定如何导出。观察实际不透明主体的边界，不按画布边界缩放；源图已有留白时，不再叠加固定 inset。需要时为 16/32px 制作简化或局部放大的变体，保留同一主体和配色，不强迫所有尺寸等比缩小一张复杂图。
3. 导出项目 Manifest 实际引用的 PNG 尺寸，保持透明边角。分别在浅色、深色工具栏背景和扩展管理页尺寸检查轮廓、对比度、边缘和主体占比。对比候选时按同一真实显示尺寸并排放置，不用放大预览代替判断。
4. 核对 Manifest 路径与构建包文件清单，重载已安装扩展后看工具栏与管理页。源码图、尺寸检查、打包通过和安装端显示是不同证据；缺少安装端访问时明确记录待验收项。

扩展 UI 的弹窗、设置页和状态交互继续走 Web/现有界面路径。图标源图与导出尺寸放在项目约定位置，记录生成或裁切方法，便于下一次修改。
