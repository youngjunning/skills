# 千问办公 Computer Use

依据当前 Computer Use 文档绑定应用。已知应用 bundle ID 为 `cn.qwenwork.desktop.mac`；先核对当前安装与窗口状态，不从文件名推断已经连接到目标应用。

```js
const app = await cua.getApp('cn.qwenwork.desktop.mac');
const state = await app.getAXState({ disableDiffing: true });
```

每次点击、输入、按键或等待后重新读取 AX 状态。优先使用当前 AX index；坐标操作必须对应当前截图。使用 `getApp()` 绑定、`getAXState()` 读取，不调用未暴露的 `getWindow()` 或 `getState()`。

## 输入与发送

输入控件可能显示了文本但未更新内部编辑器状态，中文输入或剪贴板操作也可能不完整。发送前同时核对完整原文、截图和发送按钮可用状态；仅凭 AX 中出现文本不能确认可发送。

输入超时后先检查消息是否已经发出，避免重复提交。草稿残留或按钮状态不一致时，可在授权范围内通过新任务重置，再核对输入区为空、发送按钮 disabled。一次恢复仍无法稳定输入时停止 UI 阶段，由用户接管输入，独立汇报后端检查。

## 恢复与验收边界

1. 无窗口时重新读取全局状态并绑定一次；仍不可用则报告 UI 未验收。
2. 原生通道初始化或会话内核故障时，按当前工具文档重置会话并重新确认应用清单；一次恢复仍失败就停止，不用终端模拟输入绕过链路。
3. 从被测项目确认技能名称、安装路径、测试任务、目标环境和授权范围；不把市场同名结果当作本地技能已加载，不覆盖已有安装。
4. 发送、确认、任务进度和结果卡片按 UI 实际显示记录。真实执行的事件、任务终态与产物由被测项目的协议证据验证。

本技能不包含任何具体服务的身份注入、私有查询键、Provider 协议或远端地址。UI 运行状态、脚本结果和服务端结果分别陈述；缺少目标环境或执行授权时不启动真实远端测试。
