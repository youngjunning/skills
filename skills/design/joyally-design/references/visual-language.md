# Joyally Design 视觉语言：江南山水

Joyally Design 将江南山水的空间关系转译为界面秩序：近处清楚可操作，远处安静而有层次，光与季节提供温度。用户先看见任务、内容和下一步，再感到山水的气息。辨识度来自语义色、距离、材质和节制的共同作用，而非一张风景背景。

## 色彩各司其职

| 视觉线索 | 界面职责 | 使用边界 |
| --- | --- | --- |
| 雾白 | 画布、留白和低噪声底色 | 大面积保持温和，正文与数据放在清晰表面 |
| 湖色 | 主操作、当前位置、焦点和进度 | 使用可读的深色变体，状态同时有文字或形状 |
| 水杉绿 | 成功、在线、生长与完成 | 与主操作区分；季节配色可改变色相，不改变语义 |
| 远山灰蓝 | 次级文字、结构、边界与退后的信息 | 保留可读对比度，不用低对比度制造“朦胧” |
| 深湖墨 | 标题、结论、正文和深色表面 | 建立阅读锚点，不让所有标签都同样沉重 |
| 晨光暖色 | 少量高光、提醒和季节线索 | 不铺满画布；警告、错误使用各自的语义 token |

颜色从 `Seed → Map → Alias → Component` 派生。组件消费语义角色，不直接消费风景色名；浅色、深色与四季可以变换色值，操作、状态和层级的意义保持稳定。具体值与对比度以 [统一 token 契约](token-contract.md) 和随包 token 文件为准。

## 空间与材质

- 远近由信息层级表达：前景是主要内容和动作，中景是导航与工具，背景承接氛围。对齐、字号、间距和表面先建立顺序，再加入雾、光或景观图形。
- 以 8px 节奏组织内容，4px 处理局部关系；桌面工作台保持紧凑，阅读页面给段落留足宽度和呼吸，移动端服从触控热区与系统字体缩放。
- 青瓷釉是温润、偏实的默认表面；玻璃用于外缘、导航或定位上下文。表格、表单、代码、日志、证据和长文保持不透明。每层只保留一个清楚的材质边界。
- 雾气、水纹、叶影与光斑只在外缘、空态或展示区点到为止。画面可以借景，不把真实风景照、密集插画或连续装饰放在任务前面。

## 字体、图像与动效

优先使用平台可读字体或产品已有品牌字体。标题、正文、标签和数字按阅读顺序区分；中文长标题、窄屏断行与字体放大必须在实际尺寸检查。图像承担内容或情绪时先确定它与文字和操作的关系，避免把图当作填空装饰。

交互动效解释状态变化和空间连续性，通常短而明确；雾与光若缓慢移动，应停在阅读区外，并在页面隐藏或减少动态效果时停止。静态画面仍须能表达当前状态和下一步动作。

## 验收辨识度

在真实页面上检查：主操作与阅读锚点是否一眼可见；远近层次是否帮助扫读；湖色、杉绿和暖色是否各有职责；材质是否保住正文与证据的对比度；去掉装饰后任务是否仍走得通。报告、工作台与原生界面可以有不同密度和组件形态，但共享这套语义关系。服务其他品牌时复用方法与状态契约，视觉身份由该品牌决定。
