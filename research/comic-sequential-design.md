# 漫画的连续叙事：分镜、对白与页面节奏

本笔记面向漫画制作规范。来源优先采用漫画作者、编辑、漫画教育机构及漫画创作软件的原始教学材料；下文的制作建议是基于这些资料的归纳，不是某一来源规定的固定模板。

## 核心判断

漫画的叙事单位是**有意安排的连续画面**。Scott McCloud 将日常说法简化为“sequential art”或“writing with pictures”；重点是读者通过相邻画面理解时间、动作与关系，而非看到一张插图后再读一段对白。[Scott McCloud 本人说明](https://www.scottmccloud.com/2010/08/24/why-it-works/)；[《Understanding Comics》介绍](https://www.scottmccloud.com/2-print/1-uc/index.html)。

## 可落实的画面语言

| 要素 | 一手资料中的依据 | 制作含义 |
| --- | --- | --- |
| 先定阅读路径 | 漫画作者 Steve Ellis 建议先画整页缩略稿，再决定大格、小格、嵌格和边框；格内动作应把眼睛引向下一格。[Steve Ellis 的分镜教程](https://www.clipstudio.net/how-to-draw/archives/160963) | 在生成任何精细画面前，先做整页或整段草图，能一眼看出格序和视觉重心。 |
| 用格间变化讲故事 | 漫画编辑的逐页检查要求读者能顺畅追踪格与格之间的动作；每次转场需要有可理解的主要变化。[MakingComics 编辑检查](https://makingcomics.com/2014/04/14/comic-review-checklist-part-1-flow/) | 每格至少承担一个新的观察、行动、反应或后果；连续三格不能只是同一姿势配不同说明。 |
| 让画格承担节奏 | 大格、格数、格间距和对白量都会改变阅读速度；格间空白也表示事件之间的时间。[Steve Ellis 的分镜教程](https://www.clipstudio.net/how-to-draw/archives/160963)；[MakingComics 编辑检查](https://makingcomics.com/2014/04/14/comic-review-checklist-part-1-flow/) | 关键结果可用大格或留白停顿；具体格数与宽度由情节决定，不设统一的“每页几格”配额。 |
| 视点与动作相配 | Clip Studio 的漫画教学建议建立场景后交替使用远景、中景、特写，动作可拆为预备、发生、反应；对话密集时也要画表情、物件或动作。[Clip Studio 叙事教学](https://www.clipstudio.net/en/comics-manga/design-tips/)；[漫画制作教学](https://www.clipstudio.net/en/comics-manga/comic-creation/) | 先确定读者需要看见的证据，再选镜头；人物头肩像不应成为所有画格的默认构图。 |
| 对白属于画面 | 缩略稿阶段就规划气泡位置；气泡尾巴指明说话者，阅读顺序须明确。[Clip Studio 漫画制作教学](https://www.clipstudio.net/en/comics-manga/comic-creation/)；[MakingComics 文字检查](https://makingcomics.com/2014/05/05/comic-review-checklist-part-2-words/) | 对白放进相应格内或与格形成清楚的连续关系；正文解释可以留在漫画之外，但不能替代格内的叙事对白。 |
| 区分页漫与条漫 | 传统页漫靠整页构图组织多格；竖屏条漫沿滚动方向安放格与对白，利用格距控制时间，并需在手机视窗预览。[Clip Studio 条漫教学](https://www.clipstudio.net/how-to-draw/archives/157055) | 两种格式都要设计连续阅读；竖排堆放多个独立插画卡片，本身不等于条漫。 |

## 制作与验收建议（基于上述来源的推导）

1. 写一句明确的场景变化，例如“误点同名按钮 → 发现命中错误行 → 改用所属行定位 → 再次验证”。
2. 用缩略稿确定画格顺序、每格画面信息、镜头、角色位置和对白气泡；让读者只看图与格序也能说出发生了什么。
3. 画面可以分格生成，但最终应共同构成一页或一段连续条漫；共享空间、角色位置、视觉方向和颜色，避免每格像独立海报。
4. 保持对白、气泡尾巴和技术标签可编辑，完成后同时检查整页缩略图与手机阅读宽度；随机遮住说明文字，确认画面仍能表达主要动作和结果。
5. 拒收“标题框 + 单张人物插画 + 图外聊天记录或总结框”的成品；这种结构可作为图文说明，但不足以证明完成了漫画分镜。

以上是**验收准则的建议**，不是对所有漫画类型的定义或固定版式要求。具体格数、画风、留白与对白密度应服务于故事和阅读载体。
