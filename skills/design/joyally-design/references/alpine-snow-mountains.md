# 阿尔卑斯雪山主题

以[少女峰地区的五张参考画面](../assets/references/alpine-snow-mountains/README.md)为依据：雪峰轮廓、岩雪交界、冰川谷地与远近尺度共同形成视觉语言。它适合需要清晰方向、进度和开阔感的界面；选用时仍以产品任务和既有品牌为准。

## 构图与节奏

- 用斜向山脊或谷地路径引导视线，从页面标题、当前状态走向主要操作；内容区仍沿稳定网格对齐，不让斜线改变控件几何。
- 远景提供宽阔的天空或雪原留白，中景承载导航与分组，前景用清晰的不透明表面承载正文、数据和操作。峰形只出现在外缘、展示区或空态。
- 以大块安静区域对照少量明确的高点；导航和表单保持紧凑，阅读区域保留足够行宽与间距。山脊的斜率可用于分区边界或进度导引，不延伸成密集的装饰线。

## 种子色与语义映射

下表是浅色与深色方案的起点，**不是已分发的产品 token 预设**。示例文字色与背景色的组合已按 WCAG 对比度公式核算；接入产品时仍须覆盖实际字号、组件状态和所有表面。

| 角色 | 浅色示例 | 深色示例 | 使用 |
| --- | --- | --- | --- |
| `background` / `darkBackground` | 雪雾 `#F4F7F9` | 夜山 `#142631` | 页面画布，避免纯白铺满所有层 |
| `surface` / `darkSurface` | 雪面 `#FFFFFF` | 深岩 `#1C3442` | 正文、表格、表单和证据的不透明表面 |
| `text` / `onDark` | 岩墨 `#20313E` | 雪白 `#F1F7FA` | 主要正文；对应画布对比度约 12.43:1 / 14.37:1 |
| `textSecondary` | 岩灰 `#526776` | 待逐项映射 | 浅色白色表面约 5.90:1；深色值需按实际表面验证 |
| `primaryAction` / `onPrimaryAction` | 冰川深蓝 `#245D79` / 白色 `#FFFFFF` | 待逐项映射 | 浅色主按钮约 7.20:1；主操作、当前位置与进度 |
| `primaryContainer` / `onPrimaryContainer` | 冰蓝 `#DCEEF5` / 深蓝 `#173A4D` | 待逐项映射 | 选中与轻强调，浅色示例约 10.06:1 |

蓝色表达操作与位置；成功、警告、错误继续由独立语义角色表达，不从冰蓝或日照暖色推断状态。键盘焦点需有清晰轮廓，并在相邻表面上验证。照片中的松绿可作为成功色的选色线索，晨光杏色只作少量展示高光，二者均需完成语义映射后才能进入组件。

## 材质、组件与动效

表面取雪的哑光与岩面的清晰边界：用细边框、低噪声色差和少量阴影分层。冰透感只用于远景、导航外缘或展示卡片；密集数据、输入框和长文保持不透明。按钮、标签和状态图标继续使用平台组件形态。加载与进度可以借谷地路径或山脊推进，但必须有文字状态；动效短暂，并支持 `reduced motion`。

## 接入与验收

新产品先读[统一 token 契约](token-contract.md)，把浅色、深色、焦点、成功、警告、错误和全部组件状态映射完整，再核对文字对比度、窄屏、键盘、触控、空态与打印。当前随包 JSON、CSS 与原生示例仍是青山湖预设；本主题提供视觉方向与浅色种子示例，不能把其中个别色值叠加到青山湖预设后称为完整的阿尔卑斯主题。
