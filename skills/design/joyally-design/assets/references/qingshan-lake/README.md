# 临安青山湖视觉参考

临安青山湖是 Joyally Design 设计体系的来源之一。本目录有 20 张参考画面：保留的 14 张 WebP 来自用户提供的视频截图，与 `fwork-ux` 项目内的同名参考文件保持相同字节；新增 6 张实景照片用于补充湖面、林冠和水上森林视角。截图保留字幕和播放器边框，仅用于观察湖面色阶、远山层次、水杉、季节色与日光方向；内站画册允许逐张查看原画面，但不要作为产品背景、插画或可复用的裁切图。原始视频的作者与授权信息未随截图提供，Joyally Design 的源码许可不覆盖这些截图。

将同一景点的多帧画面转译为纵向树列、雾白阅读表面、湖色层次、秋叶铜赭色与局部日光的比例关系；文字、表格和操作区保持清晰。主题显示名为「青山湖」，取景地仍是青山湖水上森林；视觉契约见[景观视觉体系](../../../references/visual-language.md)。
