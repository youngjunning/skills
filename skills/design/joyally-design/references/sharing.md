# 本地产物与可选托管

先交付通过校验的本地 HTML、资源目录或用户要求的源文件。生成位置沿用用户指定路径；未指定时使用临时目录，并在用户可访问前保留最终文件。

用户明确要求共享链接时，从其项目或本机配置选择已有且获授权的上传方式。这里不包含上传 SDK、服务地址、对象前缀、账号或凭证，不默认使用某个公司的托管服务。

上传前核对文件、目标对象和覆盖授权。上传成功后，从最终可访问 URL 读回字节并比较 SHA-256，检查响应类型、缓存和页面资源。返回了 URL 不代表内容已正确可读。验证失败时保留源文件与本地结果，并如实说明失败阶段。

图表嵌入只使用已验证的 URL。目标渲染器过滤 iframe 时，保留独立打开链接和文字摘要；生成、自包含校验、视觉检查、上传与读回分别报告。
