# 香奈儿风主题参考画面

香奈儿风（旧称“小香风”）与青山湖、西湖、苏州园林、马尔代夫、阿尔卑斯雪山并列。用户的情绪板包含包袋、山茶花、珍珠、巴黎夜景、黑白时装与暖金杂志排版。这 20 张可追溯照片只用于研究套装轮廓、滚边、纽扣和织物等局部细节，其中也有其他设计师的历史素材；主画面使用另行制作的原创视觉示意，避免展示其他品牌标识。
