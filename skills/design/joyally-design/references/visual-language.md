# 景观审美方向：视觉主题

本文件描述 Joyally Design 当前的景观审美方向。中国风、景观、时尚潮流等方向可以并列或结合；共享的是操作语义、组件状态与可读性要求，景观构图和色彩只约束选用本方向的界面。本方向从景观中提取留白、远近、框景、路径和材料的设计方法，不直接移植风景照片或地域符号。青山湖、西湖与苏州园林取材于中国景点，马尔代夫主题取材于热带环礁，阿尔卑斯雪山主题取材于少女峰地区。近处清楚可操作，远处安静而有层次；用户先看见任务、内容和下一步，再感到场景的气息。

## 共同规则

在景观方向中，留白为内容和操作留出呼吸空间；远近让前景承载行动、中景组织导航、远景提供氛围；框景与路径帮助聚焦并引导阅读。跨审美方向的共同契约是语义 token、状态、对比度和交互含义；新增方向可采用不同的空间规则。

## 五种景观视觉主题

主题是一套可复用的界面表达，定义构图、色彩、材质、节奏及其到语义角色与组件状态的映射。先收集同一景点或景观区域的多张画面，比较不同视角与局部，找出稳定的空间特征，再把它转译为一套界面。单张照片只能作为参考，不能独自决定主题。五种主题在体系中地位平等；实现进度不同不改变层级。

| 景点主题 | 画面依据 | 空间组织 | 色彩与材料 | 当前实现 |
| --- | --- | --- | --- | --- |
| 青山湖 | 20 张水上森林、水杉、湖面、远山与季节光影参考画面 | 纵向树列与柔和分层，水面留出阅读空间 | 水杉绿、秋叶铜、雾白青瓷 | 页面展示；现有四季、报告和平台 token 以此实现 |
| 西湖 | 20 张湖面、桥、堤、远山与岸线照片 | 水平长轴、宽幅视线和大块留白 | 湖蓝、石灰、清透暖纸 | 页面展示；产品 token 尚需逐项映射和校验 |

五组主题各有 20 张本地画面，分别保存在[青山湖参考目录](../assets/references/qingshan-lake/README.md)、[西湖参考目录](../assets/references/west-lake/README.md)、苏州园林的[拙政园目录](../assets/references/suzhou-gardens/README.md)和[留园目录](../assets/references/lingering-garden/README.md)、[马尔代夫参考目录](../assets/references/maldives/README.md)以及[阿尔卑斯雪山参考目录](../assets/references/alpine-snow-mountains/README.md)。青山湖其中 14 帧来自用户视频，原视频作者与授权未随截图提供，仅作为设计研究资料展示，不作为可复用产品背景。马尔代夫照片来自不同岛屿，不宣称出自同一座岛。其余照片逐张记录作者、来源与许可。画面用于成组取色和空间观察，不替代组件、token 或布局规则。

五种主题共用 `Seed → Map → Alias → Component`、操作与状态的语义、可读性和组件状态。选主题先看产品任务与品牌，再借当前取景地的景观线索校准种子色和版式；明暗、四季与材质在主题内继续变化。不能把取景地照片的颜色直接写进业务组件，也不能声称尚未映射的主题已覆盖所有平台。

苏州园林主题结合拙政园的深色框景、院落分格与留园的曲廊、山石，形成连续但有转折的路径。用墨黛、暖石和素纸色组织层级。曲廊轮廓用于展示区与分组关系；正文、表格、表单和浮层保持清晰的实色表面。深色模式以深暖灰承载阅读表面，以浅暖色保住主操作的对比度。成功、警告和错误沿用独立语义角色。

马尔代夫主题以白沙和浅海作为大面积明亮背景，用深海蓝承载标题与主操作，礁湖蓝承载定位、焦点和进度。弧形边界只用于展示区、分组外缘或空态；表单、表格、正文和浮层保持不透明。深色模式用深海底色与浅色文字，浅海蓝转为可辨识的操作强调色。成功、警告和错误继续使用独立语义角色，不由礁湖颜色代替。

## 青山湖现有预设的色彩映射

| 视觉线索 | 界面职责 | 使用边界 |
| --- | --- | --- |
| 雾白 | 画布、留白和低噪声底色 | 大面积保持温和，正文与数据放在清晰表面 |
| 湖色 | 主操作、当前位置、焦点和进度 | 使用可读的深色变体，状态同时有文字或形状 |
| 水杉绿 | 该预设的成功、在线、生长与完成 | 与主操作区分；其他方向可换种子色，不改变语义 |
| 远山灰蓝 | 次级文字、结构、边界与退后的信息 | 保留可读对比度，不用低对比度制造“朦胧” |
| 晨光暖色 | 少量高光、提醒和季节线索 | 不铺满画布；警告、错误使用各自的语义 token |

上表是青山湖主题的具体映射，不代表体系的唯一配色。颜色从 `Seed → Map → Alias → Component` 派生。组件消费语义角色，不直接消费风景色名；主题、浅色、深色与四季可以变换色值，操作、状态和层级的意义保持稳定。已实现的具体值与对比度以 [统一 token 契约](token-contract.md) 和随包 token 文件为准。

标题与正文使用满足对比度的中性文字色，不把文字色列为品牌强调色，也不用它铺大面积表面。

## 空间与材质

- 远近由信息层级表达：前景是主要内容和动作，中景是导航与工具，背景承接氛围。对齐、字号、间距和表面先建立顺序，再加入雾、光或景观图形。
- 以 8px 节奏组织内容，4px 处理局部关系；桌面工作台保持紧凑，阅读页面给段落留足宽度和呼吸，移动端服从触控热区与系统字体缩放。青山湖用树列与柔和纵向节奏，西湖用水平长轴与宽幅留白，苏州园林用院落框景与曲廊山石路径，马尔代夫用弧形岛缘和宽阔色带，阿尔卑斯雪山用斜向山脊与谷地路径；各主题都应保住导航和扫读。
- 青瓷釉是现有青山湖预设中温润、偏实的表面；玻璃用于外缘、导航或定位上下文。表格、表单、代码、日志、证据和长文保持不透明。每层只保留一个清楚的材质边界。
- 雾气、水纹、叶影与光斑只在外缘、空态或展示区点到为止。画面可以借景，不把真实风景照、密集插画或连续装饰放在任务前面。

## 字体、图像与动效

优先使用平台可读字体或产品已有品牌字体。标题、正文、标签和数字按阅读顺序区分；中文长标题、窄屏断行与字体放大必须在实际尺寸检查。图像承担内容或情绪时先确定它与文字和操作的关系，避免把图当作填空装饰。

交互动效解释状态变化和空间连续性，通常短而明确；雾与光若缓慢移动，应停在阅读区外，并在页面隐藏或减少动态效果时停止。静态画面仍须能表达当前状态和下一步动作。

## 验收辨识度

在采用景观方向的真实页面上检查：主操作与阅读锚点是否一眼可见；远近层次是否帮助扫读；每个主题的颜色是否映射到明确的语义职责；材质是否保住正文与证据的对比度；去掉装饰后任务是否仍走得通。报告、工作台与原生界面可以有不同密度和组件形态，但共享操作语义与状态契约。其他方向和品牌由各自的视觉语言决定构图与配色。
