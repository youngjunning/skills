# vibe 人格观察

用户定义的“vibe 人格”是对获准对话中可见的表达、协作和取舍方式的局部观察，不能代表完整人格，也不是 MBTI 评测。参考 [VibePortrait](https://github.com/dadwadw233/VibePortrait) 的增量证据整理思路；该工具的全历史扫描、MBTI 推分、能力评级、名人匹配、人格模拟和 GitHub 同步不进入自动蒸馏。正式 MBTI 结果只在用户主动提供时按其原始来源另行记录。

每轮只看本轮用户消息及为还原纠正所必需的相邻上下文。候选先写成“在什么场景，观察到怎样的表达或选择”，附可回查的本人原话或明确采纳的决定。优先描述具体做法，避免“内向”“控制欲”等心理归因。单次情境证据只写该情境，不扩为稳定特质；证据相反时保留两种情境或缩小范围。用户明确纠正时按纠正修订。

对目标中的同一观察按对象、行为和适用范围去重。新证据只重复已有观察时不更新；使表述更准确时原位修订，并在目标支持时留下前后版本、原因与来源。已不成立的观察撤回展示但保留历史。仅保存适合目标受众的短证据，正文标记“AI 基于对话的观察”，未知保持未知。未配置目标或无合格证据时无写入。
