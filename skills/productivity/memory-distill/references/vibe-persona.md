# vibe 人格与对话版 MBTI

用户定义的“vibe 人格”包含对话版 MBTI 四字母结果和局部行为观察。参考 [VibePortrait](https://github.com/dadwadw233/VibePortrait) 的四维组织和增量证据思路，但不照搬其历史扫描、百分比推分、能力评级、名人匹配、人格模拟或 GitHub 同步。对话版结果不是[正式 MBTI 评测](https://www.myersbriggs.org/my-mbti-personality-type/take-the-mbti-instrument/)，不能代表完整人格；页面须标明来源和局限。

目标明确授权 MBTI 时，建立 E/I、S/N、T/F、J/P 四维基线。优先使用本人对偏好的直接回答或本人确认的既有结果；必要时一次性询问四维的短问题：精力恢复、先关注事实还是可能性、重要决定先看逻辑标准还是人际影响、项目先定计划还是保留选择。问题是简短自述，不能冒充官方量表，也不填百分比。四维均有明确依据才展示四字母；有维度缺证据时标记待确认，并只问缺项。技术职业、语气、消息频率和单个工作场景不能推断维度。本人回答与工作中的局部行为不一致时，保留场景差异，不自动推翻本人自述。

每轮只看本轮用户消息及为还原纠正所必需的相邻上下文。候选先写成“在什么场景，观察到怎样的表达或选择”，附可回查的本人原话或明确采纳的决定。优先描述具体做法，避免“内向”“控制欲”等心理归因。单次情境证据只写该情境，不扩为稳定特质；证据相反时保留两种情境或缩小范围。用户明确纠正时按纠正修订。

对话版 MBTI 按目标中的同一身份更新：新自述重复既有维度时不写入；纠正某维或提供更明确的结果时更新该维与四字母，保留旧类型、日期、原因和证据。未改变字母但补充了确有价值的适用条件时更新说明。行为观察按对象、行为和适用范围去重；新证据只重复已有观察时不更新，使表述更准确时原位修订并留下前后版本。已不成立的观察撤回展示但保留历史。仅保存适合目标受众的短证据；未配置目标或无合格证据时无写入。
