# 方向与交付流程

本流程负责界面任务的范围、方向、证据与规范沉淀。平台尺寸、状态和视觉契约仍由 `SKILL.md` 指向的对应参考决定。Joyally 品牌遵循[中国风审美视觉体系](visual-language.md)：从「青山湖水上森林」「西湖」「拙政园」等景点主题中选择，先研究同一景点的多张画面，改变构图、色彩、材质、密度和内容呈现，再提炼跨主题的共同规则，同时保留语义角色、空间层次与组件状态。现有四季/材质 token 是青山湖水上森林的实现样本。

## 先确定本次任务

写清目标用户、主要任务、真实对象和内容、使用设备、现有品牌与组件、交付物和允许改动的范围。优先读取受影响页面、设计变量、代表性截图与项目现有设计规范；事实缺失时标未知。只在缺项会改变核心方向且无法推断时询问。

| 用户要做什么 | 本次做到哪里 |
| --- | --- |
| 点名元素和改法的小改动 | 直接修改；样式变化看改动区域与相邻元素，纯文案或数据变化按项目验证即可 |
| 只读设计评审 | 看实际画面和主任务路径，交位置、证据、影响、优先级与建议；不改文件 |
| 新建页面、产品或已授权的重塑 | 确定一个方向，做代表性页面或流程，验收后完成已授权范围 |
| 明确要求比较方向、版式或改动幅度 | 只制作用户要比较的维度和数量，使用相同内容与视口并排评估；选定后深化 |
| 已有页面精修或回改 | 保留已确定的品牌、信息架构与有效交互；将感受翻译成可观察的修改，核对改前改后 |
| 设计规范治理 | 对照文档、tokens、共享组件与样板页面，修复冲突或缺口；不因整理规范改业务页面 |

“设计说明”“可比较的小样”“设计稿”“可运行界面”是不同交付物。按用户要的产物完成；已经授权直接实现时，不把方向说明变成等待确认的额外关卡。

## 形成方向

先判断页面任务：阅读与内容浏览、反复操作的工作区、说服展示，或高度依赖手感的交互。产品参考用于理解该类页面的内容骨架与完成度；交互参考用于核对“触发 → 对象变化 → 反馈 → 下一状态”。引用参考时记录实际看到的画面或操作，并写明借鉴与舍弃的理由；参考的品牌、内容和业务事实不进入目标产品。

默认推荐一个方向，用几句话说明内容层级、主动作、视觉重心、关键状态和选择依据。用户已经定下方向就沿用。用户要求比较时，候选要在结构或信息呈现上有真实差异；只比较版式就固定品牌、色彩与控件语言，只比较改动幅度就保留当前页面作基线。候选共用真实内容、数据和视口，标出各自的取舍与推荐理由。可用同屏截图、原型或项目现有预览方式交付比较结果，不依赖指定生成器或额外服务。

Joyally 品牌方向按[视觉语言](visual-language.md)映射界面职责。阅读区域保持不透明；景观氛围放在外缘、空态或展示区域。其他品牌以自身资产、语义角色和用户场景建立方向。

## 从一页做到一套

先实现最能检验方向的一页或关键流程，同时覆盖主要内容、动作和加载、空、错误、成功等受影响状态。用真实长度的标题、数据与文案检查层级；模拟数据或未接入动作在交付说明中标明，不伪装成已完成的业务结果。代表性页面通过后，再沿用现有 tokens、共享组件和交互习惯扩展到其他页面。多个页面类型各取一张样板；扩展时并排检查导航、密度、按钮和状态是否漂移，把重复问题修在共享来源。

取证时在项目实际支持的桌面、窄屏和中间尺寸查看渲染结果，并检查一两个代表性交互态。截图要亲自看：文字裁切、遮挡、对比度、焦点、滚动和操作反馈无法由“截图文件已生成”证明。回改使用相同内容、视口和状态的前后画面对比；记录用户已明确认可的部分，改后逐项核对。反复修改仍没有改善同一问题时，重新检查方向假设。

按 [设计质量工作流](design-quality.md) 修复阻塞、缺失状态、层级与视觉细节，再按 [统一验收](validation.md) 核对操作、无障碍和平台差异。只做局部修改就验证局部及其相邻关系；新页面或共享系统变化要验证完整受影响路径。源码、构建、截图、真实操作和设备检查分别报告，不互相代替。

## 沉淀项目规范

稳定方向已在代表性页面上验证，且后续页面需要复用时，更新项目已有设计规范；没有规范且项目确需持续复用时，再新增项目约定的位置。记录视觉方向、品牌资产、语义角色、组件入口、样板页面、状态与平台差异，以及仍待迁移的页面。规则写成能对照页面检查的决定；数值以实际 tokens 和代码为准。区分用户确认的取舍与从现状推断的规则，不把未确认的候选写成品牌定论。

规范散落或冲突时，先列出冲突位置、代码现状与建议取舍，只收敛同一产品的规则；官网、工作台和原生端可共享品牌身份，但密度和输入规则分别写。规范只指向共享变量与样板页面，不复制整张色值表。局部例外留在组件或页面，不自动升级为全局规定。落盘后检查所引用的路径、变量和组件存在，代表性页面与规范一致。
